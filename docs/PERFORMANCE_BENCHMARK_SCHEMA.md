# STRATA Performance Benchmark Schema Specification (Phase 12)

This document defines the official schema for `performance.json`, the machine-readable performance profiling artifact generated by STRATA during reconstruction pipeline runs.

---

## 1. File Location & Naming

For every job execution, `performance.json` is written to the root of the project's workspace directory:
```
uploads/<job_id>/performance.json
```

---

## 2. Root JSON Structure

```json
{
  "schema_version": "1.0",
  "job_id": "string",
  "timestamp": "ISO-8601 UTC timestamp",
  "status": "completed | skipped | failed | cancelled",
  "error": "string (error message if failed)",
  "total_wall_clock_sec": float,
  "total_wall_clock_ms": float,
  "hardware": {
    "os_system": "string",
    "os_release": "string",
    "architecture": "string",
    "python_version": "string",
    "cpu_cores": int,
    "ram_gb": float,
    "device_type": "cpu | cuda | mps",
    "gpu_name": "string",
    "opencv_version": "string",
    "pycolmap_version": "string",
    "pytorch_version": "string"
  },
  "bottleneck": {
    "bottleneck_stage": "string",
    "bottleneck_duration_sec": float,
    "bottleneck_percentage": float,
    "recommendation": "string"
  },
  "stages": {
    "<stage_name>": {
      "name": "string",
      "status": "pending | running | completed | skipped | failed | cancelled",
      "duration_ms": float,
      "duration_sec": float,
      "input_count": int,
      "output_count": int,
      "throughput": {
        "value": float,
        "unit": "views/sec | frames/sec | items/sec | points/sec"
      },
      "device": "cpu | cuda | mps",
      "cache": {
        "hit": boolean,
        "key": "string | null"
      },
      "fallback": {
        "used": boolean,
        "name": "string"
      },
      "error": "string",
      "details": { ... }
    }
  }
}
```

---

## 3. Field Definitions

### 3.1 Hardware Capability Discovery (`hardware`)
- **`os_system`**: Operating system (e.g. `Darwin`, `Windows`, `Linux`).
- **`cpu_cores`**: Number of available logical CPU cores.
- **`ram_gb`**: Installed system memory in Gigabytes.
- **`device_type`**: Primary compute backend (`cpu`, `cuda`, or `mps`).
- **`gpu_name`**: Name of GPU device (or `CPU Only`).
- **`pytorch_version`**: Version of PyTorch installed.
- **`pycolmap_version`**: Version of PyCOLMAP installed.

### 3.2 Bottleneck Analysis (`bottleneck`)
- **`bottleneck_stage`**: The stage consuming the highest proportion of wall-clock time.
- **`bottleneck_percentage`**: Proportion of total active stage execution time (0.0% – 100.0%).
- **`recommendation`**: Actionable optimization recommendation targeted to the bottleneck.

### 3.3 Stage Metrics (`stages.<stage_name>`)
Supported stages include `frames`, `sparse`, `depth`, `dense`, `georef`, and any dynamic plugin stages.
- **`duration_sec` / `duration_ms`**: Measured wall-clock time spent in the stage.
- **`input_count` / `output_count`**: Number of input entities processed vs output artifacts produced.
- **`throughput`**: Computed processing rate (`value` and `unit`).
- **`device`**: Actual hardware backend utilized during stage execution.
- **`cache.hit`**: `true` if the stage was skipped via deterministic fingerprint cache validation.
- **`fallback.used`**: `true` if a fallback engine was triggered (e.g. OpenCV fallback instead of COLMAP).

---

## 4. Verification Rules
1. Timings MUST be real wall-clock durations measured using `time.perf_counter()`.
2. No simulated or hardcoded values are allowed.
3. Every completed stage MUST include non-negative duration and throughput metrics.
